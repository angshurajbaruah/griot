# Decisions

- 2026-10-27: Named the product Griot (was TabBack). A griot keeps a community's story and tells it back.
- 2026-10-27: Core feature is a one-tap park note when leaving a task, plus an automatic trail. Competitors only guess context after the fact.
- 2026-10-27: Chrome extension, plain HTML, CSS and JavaScript with no build step, so a non-developer can read and run it.
- 2026-10-27: Local-first. Data stays in chrome.storage.local, no network calls, no page content read.
- 2026-10-27: Brand: earth palette with no blue, BackOut for titles, hand-painted swirl mark.
- 2026-10-27: Milestone 1 asks only for the `tabs` permission, the one needed to read tab titles and links. The other approved ones (tabGroups, storage, idle) get added in the milestone that first uses them, so the install prompt stays as short as possible.
- 2026-10-27: The popup shows a favicon only when Chrome already holds it as an image (data:). Otherwise it shows the site's first letter, because loading a favicon link from the site would be a network request.
- 2026-10-27: Moved the icons to assets/icons/ and the brand SVGs to assets/brand/ to match the structure in CLAUDE.md.
- 2026-10-28: Added a welcome back card on return from idle. Most breaks start without warning, so a park prompt at leave time often has nobody to answer it.
- 2026-10-28: Added the `favicon` permission (owner approved) so site icons come from Chrome's local favicon store. Showing them makes no network request, which keeps the privacy rule; it replaces the first-letter chips.
- 2026-10-28: Tab titles drop notification counts like "(176)" before they are shown, drafted from or saved. The counts are noise, change every minute and would make two copies of one page look different.
- 2026-10-28: Milestone 2 adds the `storage` permission, the first time Griot saves anything.
- 2026-10-28: Left the "Close these tabs after parking" checkbox off the park card for now. Closing tabs before "Pick up" exists (milestone 3) could lose them; revisit once threads can be reopened.
- 2026-10-28: The park card's eyebrow says "This window" when you park by hand. "Away for 10 minutes" from the design only fits an idle prompt (milestone 5).
- 2026-10-28: The draft note uses words repeated across tab titles ("Looking into Clay and Apollo."), or the current tab's name if nothing repeats. Simple, explainable, and always labelled as Griot's guess.
- 2026-10-28: The home screen shows parked threads in place of the open-tabs list from milestone 1. The home design has no tab list, and the park card already shows the current window's tabs.
- 2026-10-28: On home, the newest thread is a big "Continue thread" card with the brown Pick up button; older threads are small cards with an outlined Pick up, so there is one primary button per screen.
- 2026-10-28: A thread stays on home after Pick up. Nothing in milestone 3 says it should go away, and "Mark done" (milestone 4) is how a thread leaves.
- 2026-10-28: Finding from real use: drafts latched onto site names ("Google", "YouTube") and guessed a topic from one stray word. The draft now ignores each tab's own site name and plain numbers, and when no word repeats across tabs it uses the current tab's title as-is instead of guessing.
- 2026-10-28: Site icons get a hairline border, because white icons disappeared against the light background.
- 2026-10-28: Finding from real use: Pick up landed on the wrong tab. Each saved tab now has an `active` flag for the tab you were on when parking, and Pick up selects it.
- 2026-10-28: Finding from real use: a whole window is not a thread, so unrelated tabs came along. The park card lists the window's tabs with checkboxes; the tab you are on and tabs sharing a word with the note start ticked, and only ticked tabs are saved. Ticks are set once when the card opens, so editing the note never undoes your choices.
- 2026-10-28: Finding from real use: Pick up opened duplicates of tabs that were already open. If a window already has at least half of the thread's tabs, Pick up switches to it, adds only the missing tabs and selects the saved tab; otherwise it opens a new window.
- 2026-10-28: Finding from real use: the guessed topic grabbed stray words that happened to appear twice. A word now counts as the topic only if it is in at least a third of the tabs (and at least two); otherwise the draft is the current tab's title.
- 2026-10-28: The trail records a visit when the page in the tab you are looking at loads, changes address or changes title, and when you switch tabs. Only http and https pages, only title, link and time, at most 200 visits per window. Background tabs that load but are never looked at are not visits.
- 2026-10-28: Trails are cleared when Chrome starts, because Chrome reuses window numbers after a restart and old trails would mix with new windows.
- 2026-10-28: Parking copies the window's trail into the thread, minus visits to tabs you unticked, so an unrelated tab does not leak into the story.
- 2026-10-28: Delete asks inside the screen ("Delete this thread? This can't be undone.") rather than with a browser pop-up, so it matches the design and keeps focus in the popup.
- 2026-10-28: Review finding: after unticked tabs were removed from the trail, the same page could appear twice in a row (YouTube, Netflix unticked, YouTube). Parking now merges a page that repeats the one just before it.
- 2026-10-28: Review finding: the guess said "Looking into Product." because short words like "X" were skipped. If the top topic word is usually followed by the same word in enough tabs, the draft keeps both ("Looking into Product X."). A grown phrase is the whole topic, so it never reads "Morocco national and team".
- 2026-10-28: Owner request: after Pick up, show a "You were here" reminder with the note and next step. Griot's popup closes as soon as Chrome switches windows, and showing it on the page would need access to every site, so it is a Chrome notification. Added the `notifications` permission (owner approved). It is made locally and sends nothing.
- 2026-10-28: Pick up now runs in the background script instead of the popup. The popup closes when Chrome switches windows, which could cut the work off halfway (before the saved tab was selected).
