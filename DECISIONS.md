# Decisions

- 2026-10-27: Named the product Griot (was TabBack). A griot keeps a community's story and tells it back.
- 2026-10-27: Core feature is a one-tap park note when leaving a task, plus an automatic trail. Competitors only guess context after the fact.
- 2026-10-27: Chrome extension, plain HTML, CSS and JavaScript with no build step, so a non-developer can read and run it.
- 2026-10-27: Local-first. Data stays in chrome.storage.local, no network calls, no page content read.
- 2026-10-27: Brand: earth palette with no blue, BackOut for titles, hand-painted swirl mark.
- 2026-10-27: Milestone 1 asks only for the `tabs` permission, the one needed to read tab titles and links. The other approved ones (tabGroups, storage, idle) get added in the milestone that first uses them, so the install prompt stays as short as possible.
- 2026-10-27: The popup shows a favicon only when Chrome already holds it as an image (data:). Otherwise it shows the site's first letter, because loading a favicon link from the site would be a network request.
- 2026-10-27: Moved the icons to assets/icons/ and the brand SVGs to assets/brand/ to match the structure in CLAUDE.md.
- 2026-10-28: Added a welcome back card on return from idle. Most breaks start without warning, so a park prompt at leave time often has nobody to answer it.
- 2026-10-28: Added the `favicon` permission (owner approved) so site icons come from Chrome's local favicon store. Showing them makes no network request, which keeps the privacy rule; it replaces the first-letter chips.
- 2026-10-28: Tab titles drop notification counts like "(176)" before they are shown, drafted from or saved. The counts are noise, change every minute and would make two copies of one page look different.
- 2026-10-28: Milestone 2 adds the `storage` permission, the first time Griot saves anything.
- 2026-10-28: Left the "Close these tabs after parking" checkbox off the park card for now. Closing tabs before "Pick up" exists (milestone 3) could lose them; revisit once threads can be reopened.
- 2026-10-28: The park card's eyebrow says "This window" when you park by hand. "Away for 10 minutes" from the design only fits an idle prompt (milestone 5).
- 2026-10-28: The draft note uses words repeated across tab titles ("Looking into Clay and Apollo."), or the current tab's name if nothing repeats. Simple, explainable, and always labelled as Griot's guess.
- 2026-10-28: The home screen shows parked threads in place of the open-tabs list from milestone 1. The home design has no tab list, and the park card already shows the current window's tabs.
- 2026-10-28: On home, the newest thread is a big "Continue thread" card with the brown Pick up button; older threads are small cards with an outlined Pick up, so there is one primary button per screen.
- 2026-10-28: A thread stays on home after Pick up. Nothing in milestone 3 says it should go away, and "Mark done" (milestone 4) is how a thread leaves.
- 2026-10-28: Finding from real use: drafts latched onto site names ("Google", "YouTube") and guessed a topic from one stray word. The draft now ignores each tab's own site name and plain numbers, and when no word repeats across tabs it uses the current tab's title as-is instead of guessing.
- 2026-10-28: Site icons get a hairline border, because white icons disappeared against the light background.
- 2026-10-28: Finding from real use: Pick up landed on the wrong tab. Each saved tab now has an `active` flag for the tab you were on when parking, and Pick up selects it.
- 2026-10-28: Finding from real use: a whole window is not a thread, so unrelated tabs came along. The park card lists the window's tabs with checkboxes; the tab you are on and tabs sharing a word with the note start ticked, and only ticked tabs are saved. Ticks are set once when the card opens, so editing the note never undoes your choices.
- 2026-10-28: Finding from real use: Pick up opened duplicates of tabs that were already open. If a window already has at least half of the thread's tabs, Pick up switches to it, adds only the missing tabs and selects the saved tab; otherwise it opens a new window.
- 2026-10-28: Finding from real use: the guessed topic grabbed stray words that happened to appear twice. A word now counts as the topic only if it is in at least a third of the tabs (and at least two); otherwise the draft is the current tab's title.
- 2026-10-28: The trail records a visit when the page in the tab you are looking at loads, changes address or changes title, and when you switch tabs. Only http and https pages, only title, link and time, at most 200 visits per window. Background tabs that load but are never looked at are not visits.
- 2026-10-28: Trails are cleared when Chrome starts, because Chrome reuses window numbers after a restart and old trails would mix with new windows.
- 2026-10-28: Parking copies the window's trail into the thread, minus visits to tabs you unticked, so an unrelated tab does not leak into the story.
- 2026-10-28: Delete asks inside the screen ("Delete this thread? This can't be undone.") rather than with a browser pop-up, so it matches the design and keeps focus in the popup.
- 2026-10-28: Review finding: after unticked tabs were removed from the trail, the same page could appear twice in a row (YouTube, Netflix unticked, YouTube). Parking now merges a page that repeats the one just before it.
- 2026-10-28: Review finding: the guess said "Looking into Product." because short words like "X" were skipped. If the top topic word is usually followed by the same word in enough tabs, the draft keeps both ("Looking into Product X."). A grown phrase is the whole topic, so it never reads "Morocco national and team".
- 2026-10-28: Owner request: after Pick up, show a "You were here" reminder with the note and next step. Griot's popup closes as soon as Chrome switches windows, and showing it on the page would need access to every site, so it is a Chrome notification. Added the `notifications` permission (owner approved). It is made locally and sends nothing.
- 2026-10-28: Pick up now runs in the background script instead of the popup. The popup closes when Chrome switches windows, which could cut the work off halfway (before the saved tab was selected).
- 2026-10-28: Milestone 5 adds the `idle` permission (on the approved list). Chrome reports "idle" after 60 seconds without input, so the break is counted from a minute before that report. A break of 10 minutes or more gets a welcome back card.
- 2026-10-28: The welcome back card is built from the trail of the window you were in, using only pages from the 3 hours before the break. Pages visited after you come back (like the tab you land on) are left out, so "You stopped here" is the last page before the break.
- 2026-10-28: Guessing rules, no AI: a title with "vs", "versus", "compare … and …" or "… and … comparison" plus both products' own pages in the trail = "comparing X and Y". A product's page is one whose title starts with its name or whose address contains it. A tutorial or "how to" page for one of them after the comparison = Next guess "Sign up for X?" and the main button goes to X's page. Without a comparison the guess is the repeated words, as on the park card.
- 2026-10-28: The welcome back card shows once on the next popup open, and again whenever you click its notification. Any of its buttons forgets it, and it expires after 12 hours, so home is never blocked.
- 2026-10-28: "That's not it" opens the park card for that window with an empty note, so the correction is in your own words. Tabs are still pre-ticked from Griot's draft.
- 2026-10-28: The page count line says "7 pages · 4:02 pm to 4:40 pm" instead of the design's "2 articles, a comparison, 2 product sites…". Sorting pages into kinds would need more guessing rules than the milestone asks for.
- 2026-10-28: Alt+Shift+P (Option+Shift+P on a Mac) opens the popup on the park card. Chrome can change the key in chrome://extensions/shortcuts.
- 2026-10-28: Closing a window with 3 or more web pages shows a "Park this thread?" notification; clicking it opens the park card with that window's tabs. Griot keeps a copy of each window's tabs in session storage (emptied when Chrome quits) because a closed window's tabs can't be read. No prompt if every page is already in a parked thread (a window opened by Pick up), and never twice for one window within an hour.
- 2026-10-28: Finding from real use: the "You were here" notification never appeared on the owner's Mac (system notifications for Chrome were off or silent). Griot now opens its own popup over the tabs after Pick up, on a "You were here" screen with the note, where you stopped and Next. This needs no system setting. The notification is only a fallback when Chrome won't open the popup.
- 2026-10-28: Owner request: the 10-minute break is about one window, not the whole computer. Griot now notes when you leave each window (switching to another window or app, or the computer going idle while it is in front) and shows welcome back when you return to that window after 10 minutes or more. The welcome back card and the closed-window prompt also open Griot's popup first, with a notification as fallback.
- 2026-10-28: Finding from real use: neither notifications nor Chrome opening the popup by itself worked on the owner's Mac. Owner decision: messages live only inside Griot's popup. Removed all notifications and the `notifications` permission. A welcome back card or a closed window to park now waits inside the popup, and a small ochre dot on Griot's icon says something is waiting.
- 2026-10-28: Chrome closes the popup the moment it switches tabs (checked in a test), so "You were here" cannot stay on screen after you land. Pick up now shows "You were here" first (note, where you stopped, Next) while the tabs come back quietly in the background, and "Take me there" jumps to the saved tab.
- 2026-10-28: Finding from real use: Pick up opened a new window. Pick up never opens a new window now: if a window already has most of the thread's tabs it adds the missing ones there, otherwise it adds them to the window you are in.
- 2026-10-28: The closed-window offer is a card on home ("You closed a window with 3 tabs. Park it…?" with Not now and Park it) instead of a prompt. It lasts an hour.
- 2026-10-28: Milestone 6 settings: welcome back on or off, closed-window offer on or off, and "Pause Griot for today" (until midnight; nothing is recorded or offered). The design's "When I'm idle for 10 minutes" now reads "When I come back to a window after 10 minutes", because the break is counted per window.
- 2026-10-28: "Never track these sites": banking and health sites are always blocked, matched by words in the address (bank, health, pharmacy…) and a short list of well-known sites. You can add your own sites; adding one also removes its pages from every trail. Blocked sites are left out of trails, the park card and the closed-window copy.
- 2026-10-28: "Delete all threads and trails" asks first on the same screen. Settings are kept, so a fresh start keeps your blocked sites.
- 2026-10-28: v0.7 adds motion, matching the preview the owner approved: the woven strip slides in when the popup opens, each screen's parts rise in a quick stagger, deeper screens slide in from the right and back slides from the left, parking tucks the card away, the trail line draws itself, the "You stopped here" dot pulses twice, "Take me there" shimmers while tabs come back, settings use sliding switches. Everything is 120 to 520 milliseconds and switches off when the computer's "Reduce motion" setting is on.
- 2026-10-28: Sounds are short kalimba-like plucks made by the browser's audio engine (lib/sound.js), so there are no audio files. Park, pick up, mark done and delete each have one; they follow the "Sounds when I park, pick up or finish" switch.
- 2026-10-28: Owner request: a sound when you come back to a window, since the popup can't open by itself on the owner's Mac. Griot plays a soft three-note chime from a hidden page (Chrome's `offscreen` permission, owner approved; checked in a test that it plays without a click). One chime per return, with its own switch.
- 2026-10-28: The icon badge shows how long you were away ("25m", "2h") instead of a dot when a welcome back card is waiting; a closed window still shows a dot.
- 2026-10-28: When you come back on a different tab, Griot puts the tab you left into an ochre tab group called "You were here" (the approved `tabGroups` permission) so it shows in the tab bar. It skips tabs already in your own groups, and the label goes when you open that tab or use the welcome back card. It has its own switch.
- 2026-10-28: Owner request: real site icons everywhere a page is listed (home cards, park card, trail, "You stopped here"). Each icon sits on a tile that picks its colour from the icon itself: light icons such as a white logo get a dark brown tile, others a light tile, so no icon blends into Griot's colours.
- 2026-10-28: Added the MIT license, so the code is legally open source. Rewrote the README for people outside the project: demo GIF, screenshots, install steps, privacy stance and a table of every permission with its reason. Screenshots use made-up sites so no real brand appears.
- 2026-10-28: Repositioned around the automatic comeback. A competitor scan found small extensions that already save tabs with handoff notes (Restora Tab Handoff is nearly identical to parking) and browser AI features that summarize your history (Edge Copilot Journeys, Gemini in Chrome). What only Griot does is notice that you came back to a window and show where you stopped, with nothing saved first and no AI. The README and brief now lead with that; parking with a note is presented as the optional extra.
